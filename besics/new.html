Git :

Git is a distributed version control system designed to handle everything from small to very large projects with speed and efficiency. It helps you keep track of code changes, collaborate with other developers, and manage different versions of your codebase.

Git Hub:

GitHub is a web-based platform for hosting Git repositories, offering tools for version control, collaboration, and project management. It was founded in 2008 in the United States, with its headquarters located in San Francisco, California. The platform combines the power of Git, a distributed version control system, with features that make it easier for developers to work together on projects of any size.
